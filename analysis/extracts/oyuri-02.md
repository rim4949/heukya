## 3. 주인공(오유리) 정밀 분석

### 3-1. USER 턴 서술 형식
- **시점**: 주어를 생략하고 '제/저'를 쓰는 재귀형 3인칭 서술이 기본("제 손에 쥐어진다니", "저를 사이에 두고"). 화자 내면에 밀착된 자유간접화법에 가까움. 일부 턴은 "오유리는 …"으로 시작하는 완전한 3인칭 작가 서술(USER 106~108, 111. L6542, L6546, L6550, L6593).
- **대사 표기**: 화자 태그 없이 대사 줄을 단독으로 두고 앞뒤에 지문을 붙임. 대사가 1~2줄, 지문이 1~3줄인 구성이 표준. 따옴표는 쓰지 않음.
- **길이**: 대체로 짧음(1~6줄). 성적 장면 구간(USER 99~104)과 외출 준비 서술(USER 120~122)은 지문 비중이 높음. 대사만 한 줄인 턴도 많음(USER 95 "권도건, 서무진.", USER 128 "잘생기면 돼요, 전.", USER 129 "다정하면 더 좋고.").
- **줄바꿈 습관**: 대사 → 빈 줄 → 지문 → 빈 줄 → 대사. 지문은 과거형(-었다/-았다)을 기본으로 현재형(-ㄴ다)이 섞임("앞장선다", "물었다", "웃는다").
- **문체 특징**: 지문에 속어와 비속어가 섞이고("재력 좆된다", "삼류영화 속 양아치 같은 느낌"), 자기 감정을 직설적으로 요약함("집착과 소유욕은 제게 큰 장애물이 되지 않았다" L5652). 의성·의태어가 잦음: 하하, 흥흥~, 호다닥, 베싯/베시시, 헤실헤실, 눈을 데록 굴리다, 크으, 으엑, 꼴깍, 볼을 갉작이다.
- **오타 경향**: "믈어봐도"(L5727), "그겣의외라"(L7462), "짓씹엇다"(L6419), "어디사도"(L10393), "실면서"(L11226), "느그러지는"(L10980), "권도권"(L8721, L10124). 빠르게 타이핑하는 습관으로 보임.

### 3-2. 말투
- **존댓말 기본**: 두 남자에게는 해요체("~요", "~죠", "~잖아요", "~거든요"). 길게 늘인 대답 "네에", "네에, 네에"(L7163, L7181, L9074, L11488).

- **문장 리듬**: 말줄임표가 많음("아니이...", "까먹었어요. 원래도 먹는 거 귀찮아해서...", "형은 진짜 사고 칠 것 같으니까..."). 쉼표로 끊어 말함("깊어, 깊어, 깊다,구..."). 말끝을 흐리며 툴툴거리는 어조.

### 3-5. 상황별 대처 패턴
- **위기·통제**: 정면으로 맞서지 않고 천진한 말이나 엉뚱한 제안으로 판을 흔듦(단톡방, "사이좋게 지내요", "둘 다 주인"). 통제가 선을 넘으면 감정을 빼고 차갑게 철수 선언("그럼, 그냥 집에 가죠. 서로 시간낭비인 것 같은데." L8042). 이 '체념의 한 수'가 두 남자를 물러서게 하는 가장 강한 카드로 작동함.

- **분노·실망**: 큰소리 대신 "무감하게 올려다본다", "지친 투로 대꾸했다"(L8040, L8044).

## 4. AI 측 캐릭터 패턴

> 문체 변화 주의: L8288 무렵(AI 122)부터 AI 서술의 결이 크게 바뀜. 노골적 폭언이 크게 줄고, 짧은 문장, "──" 대시, 인물 속마음 "──씨발, …" 독백 삽입, 수치 묘사("0.5초", "2초", "196/189")가 등장함. 같은 위치부터 "재개발 구역"이라는 의미 없는 줄이 반복 삽입됨(9장). 같은 시점에 유리의 '명령 금지·음담 금지' 규칙(L8137)이 시행되어 서사적 이유도 있음.

### 권도건
- **말투**: 전면 반말. 욕설 빈도가 극히 높음(씨발/씨팔, 좆만아, 개새끼, 걸레, 썅년아, 지랄하네, 좆 까). 확인형 어미 "알아들어?", "어?", "엉?". 명령형 "입 벌려", "내려", "타", "먹어".
- **후반부 변화**: 짧고 무뚝뚝한 문장. 감정이 실릴 때 "……", "씨발." 한 마디. "개 괜찮았어"처럼 짧게 솔직함.
- **호칭(유리)**: 좆만아(기본, 전반) → 아가(L5604에 1회, L8627부터 상용, "유리에게만 허락된 이상한 다정함" L9691) → 화가 나면 "유리."(L9611: 이름이 나오면 기분이 안 좋을 때) → 확인하듯 "야, 유리."(L9781). 씨발년아, 씨발아(애칭처럼 섞임).
