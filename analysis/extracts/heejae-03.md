## 3. 주인공(신희재) 정밀 분석

### 3-1. USER 턴 서술 형식
- **대사 표기**: 대사를 따옴표 없이 독립된 줄로 쓰고, 지문은 3인칭 서술("신희재는 ~했다")로 별도 줄. 예: L11375 "오유리 씨는 어디다 놨어, 아저씨." / L11377 "신희재는 도진욱과 시선을 마주한 채 서늘하게 물었다." 화자 접두어("신희재 |")는 USER 턴에서 거의 안 씀.
- **인칭**: 지문은 3인칭이나 내면 서술은 자유간접화법으로 1인칭에 가까움("제", "저"를 신희재 지칭으로 사용: "제 몫의 접시", "저를 내려다보는", "제 잠버릇이 그런 거라니") L12220, L15513.
- **길이**: 대부분 1~4줄의 짧은 턴. 단답 1줄 턴 다수("가야 돼?" L12300, "여기." L12454, "라면." L16142, "!보고서"). 예외적 장문: USER 195(L11768–L11818, AI식 서술 혼입), USER 222(L12981 준비 장면), USER 252(L14547–L14791, 대리 작성 장문).
- **지문 비율**: 짧은 턴은 대사 위주, 감정 장면에서는 지문만으로 된 턴(USER 245–250 소파 장면 L14078–L14233, USER 258·260 잠버릇 설정).
- **명령어**: `!보고서`(L11954, L12575, L13668, L14853), `!이벤트`(L11988, L13704, L16335), `!기사`(L14885), `!한기현폰`(L14951), `!전명후폰`(L15000). 시간 점프 지시 "일주일이 지났다"(L11987), "어느날"(L13703), "다음날"(L15049, L16854), "한 시간 뒤 두 남자가 출근했다"(L16308).
- **줄바꿈 습관**: 대사와 지문을 빈 줄로 분리. 지문 중간에 쉼표로 끊고 다음 줄 대사("돌아올 이유," → "응." → "그땐 몰랐지만 지금은 있었다." L12413–L12417).
- **오타**: "조용리"(L11514), "뒷자석"(L11514), "그렇개"(L14233), "뫃인"(L14791), "포장이"(L16694), "담덤하게"(L13468), "따올리며"(L16505), "한웅큼"(L16144). 빠른 타이핑 성향.
- **기호**: `*`로 시작하는 지문 1회 L14138. 말줄임 "..." 빈번.
