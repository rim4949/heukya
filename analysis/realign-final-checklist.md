## A. 확정 사실 (모든 문서가 이것과 맞아야 함)
1. 흐름: 강제 동거 → 오유리 고백(로그 8월 말) → 두 남자 즉답 안 함(무게 과소평가, 소유적 시선, 정보 비대칭·통제) → **2027.10 초(10.08 이전) 임신 확인 → 숨김 → 도주 → 서림동/과거 생활권(거처 없음) → 올림픽대교(비) → 두 남자 발견 → 오유리가 안겨 귀환** → 두 남자가 오유리를 독립된 인격체로 재인식 → **10.08 권도건 정식 응답 → 10.15 서무진 정식 응답** → 상호 연애 관계로 본격 전환. 일자는 `2027.10 초 (10.08 이전)`로만 표기(임의 일자 금지).
2. 올림픽대교는 연애의 완성점이 아니라 **두 남자의 인식이 바뀌는 전환점**. "안아줘요"/"집에 가고 싶어"는 **답을 받은 뒤의 말이 아니다**.
3. 오유리의 도주 동기 = 임신 공포 + 답을 받지 못한 불안 + 관계 비대칭 + 선택권 상실 공포. 올림픽대교에서 "사라지고 싶다/뛰어내리면 끝날까" 정도의 생각이 스칠 수 있으나 치밀한 자살 계획은 아님(서술은 방법·수단 없이 감정·정황에 한정).
4. 나이: 오유리 26 / 서무진 35 / 권도건 36(2027.10.08부터 37). 올림픽대교 구간 26/35/36 표기 가능. 2027.12.24부터 오유리 27.
5. **출산 날짜는 미확정(⚠)**: 계산 2028.04.01~04.20(확인 10월 초 + 5~6주 + 33주) vs 개정표 2028.06 말~07 초 — 양립 불가. 출산 날짜·쌍둥이 월령·임신 주수에 의존하는 서술은 조건부로만, 하나를 채택하지 않는다.
6. 로그 11월·12월 이벤트(11.22·11.28·12.05·12.12·12.18·12.24 생일·강릉·12.25·12.31 등)는 연애 본격 전환 **이후**의 로그 날짜 그대로 유지 가능. 단 임신기 신체 상태 미반영 → `[임신기 상태 반영 필요]`(자동 삭제 금지). 12월 사건 선후 충돌(구 D-01~D-13)은 **소멸**.
7. 롯데월드 2028.02.13: 임신 약 23주 3일~26주 1일(5~6주 가정, ⚠-출산 의존). 고강도 기구(바이킹·후렌치볼트·혜성특급·자이로드롭·아틀란티스·파라오의분노)·후룸라이드 = `수정 후보`, 나머지 유지.
8. 오유리 지식: 표면 정보(태광 검색·출퇴근 패턴·겉 직함·사업체)만 앎 / 실질적 권력·범죄 조직 내 역할·정확한 업무·위험한 일의 범위는 모름.
