## 6. 동의·권력·작성 주의
- 두 남자는 올림픽대교에서 오유리를 **강제로 데려가지 않는다**(패치 v3). 임신을 안 뒤에도 허락 없이 배에 손대지 않는다. 안기 전 확인("걸을래, 안아줄까").
- 임신했다고 오유리를 수동적·환자 취급으로 쓰지 않는다(오유리.md·oyuri.md의 작가 금지 목록 유지).
- **올림픽대교의 절망 장면**: 작가 지시는 "그냥 사라지고 싶다 / 여기서 뛰어내리면 끝날까 정도의 생각이 스칠 수 있음, 치밀한 자살 계획은 아님, 주저앉아 운다"이다. 서술은 감정과 정황에 한정하고 방법·수단을 구체화하지 않는다. 두 남자의 발견은 처벌이 아니라 상태 확인과 보호로 이어진다.
- 아이(권유건·서유진)에 대한 성적 표현은 어떤 형태로도 쓰지 않는다. 성적 장면 세부는 이 DB에 옮기지 않는다.

## 7. 오유리의 지식 범위 (작가 기준)
표면 정보(태광 관련 검색, 출퇴근 패턴, 겉 직함·사업체)는 안다. 실질적 권력, 범죄 조직 내 역할, 정확한 업무, 위험한 일의 범위는 모른다. "직업명조차 모른다"가 아니라 "표면만 알고 실체를 모른다". 흑야회·태광회 조직 기원 등은 자동 공유되지 않는다.

## 8. 전파 규칙 (이후 모든 문서에 적용)
- **전파함**: 현재 나이 변경에 따른 과거 나이 / 관계 단계 변경에 따른 호칭 / 임신·출산에 따른 신체 상태 / 자녀 존재 여부 / 연애·약혼·결혼 상태 / 그 상태를 전제로 한 장면.
- **자동 전파 안 함**: 독립 사건의 연도 / 생일 / 조직 사건 / 다른 캐릭터의 사건 / "N년 전" 기간 / 촬영·행사·업무 일정. 인과관계가 있을 때만 날짜 이동. 날짜 일괄 -1년 금지.
- 새 설정·날짜를 정합성을 맞추려고 임의로 만들지 않는다. 계산으로 확정되지 않으면 충돌 목록에 남긴다.

1. **⚠ 출산 날짜·임신 주수 불일치(신규).** 임신 확인이 2027.10 초(10.01~10.07)로 이동했는데 패치 v3 PATCH 07의 확인 시 "약 5~6주"와 개정표 "출산 2028.06 말~07 초(33주 전후)"가 그대로다. 계산: 5~6주 가정 → LMP 2027.08.14~09.02 → **33주 = 2028.04.01~04.20**. 출산을 06 말~07 초로 두면 LMP가 2027.11.10~11.19가 되어 10월 초 임신 확인과 양립 불가. 어느 쪽을 바꿀지(출산 날짜 / 확인 시 주수 / 33주 조산 전제) 지시 필요 — **임의로 고르지 않는다.** 이에 종속: 쌍둥이 월령(프로포즈 약 9.9~10.5개월 vs 개정표 기준 약 7~8개월), 롯데월드 주수, 임신기 장면 전부.
2. 올림픽대교 정확 일자(10월 초 10.08 이전). 그리고 로그 10.06 사건들(오정태 태광 난입·서림동 방화·응급실)과의 선후 — 지시 없음.
3. 연애 본격 전환의 정확 시점(10.15 이후)과 "연인" 명칭을 쓰기 시작하는 시점. (heejae 로그 10.11의 "서무진의 연인 오유리"는 권도건 응답(10.08) 이후·서무진 응답(10.15) 이전.)
4. 쌍둥이 정확 출생일, VEIL 데뷔일, 파리 촬영·2031.09 육아 장면 날짜.
5. 로그 2027.10~2028.02 장면(11월·12월 이벤트, VEIL 계약·화보 등)의 임신기 신체 상태 반영 방식.
6. 오유리 아버지 이름(오정태/오창식), 쌍둥이 출생 순서, 한기현 생일(3/22 vs 1/30), heejae 10.11 vs oyuri 10.16 납치 날짜 차이, 현성락 키·근속 — 임의 확정 금지.
