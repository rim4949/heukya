## 0. 적용 규칙 (작가 지시)
1. 현재 나이 변경 → **과거 사건 당시 나이는 재계산**한다.

## 4. 2027.10 초 올림픽대교 구간과 연쇄 (최종 개정 `directive-oct-2027-pregnancy-bridge-FINAL`)
- **순서**: 강제 동거 → 오유리 고백 → 두 남자 즉답 안 함 → **2027.10 초(10.08 이전) 임신 확인 → 숨김 → 도주 → 서림동/과거 생활권 → 올림픽대교 → 두 남자 발견 → 귀환** → 10.08 권도건 응답 → 10.15 서무진 응답 → 상호 연애 본격 전환. 정확한 일자는 [불명].

- **임신 주수가 걸린 로그 장면(5~6주 가정 시 `[조건부]`)**: 12.05 약 13주 3일~16주 1일 / 12.24 약 16주 1일~18주 6일 / 12.31 약 17주 1일~19주 6일 / 롯데월드 2028.02.13 약 23주 3일~26주 1일.
