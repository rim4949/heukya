# author/ — 작가 지시 레이어 (최우선 canon)

이 폴더는 작가(프로젝트 소유자)가 직접 내린 설정·해석·수정 지시를 보관한다.

## 우선순위
1. **장면별 작가 지시** (해당 장면 한정, 채팅으로 내린 구체적 행동/감정 지정)
2. **author/** 의 작가 지시 (이 폴더) — 원본 로그·분석 결과보다 우선
3. canon/, characters/, stories/ 의 분석 결과 (원본 로그 기반)
4. 원본 로그 (최근 로그 우선)

## 규칙
- 작가 지시는 원문 그대로 보존한다. 요약·재해석해서 덮어쓰지 않는다.
- 분석 결과(characters/*.md 등)가 작가 지시와 충돌하면 작가 지시를 따르고, 충돌 사실은 canon/contradictions.md 에 "작가 지시로 해소"로 기록한다.
- 새 지시가 들어오면 directives-log.md 에 날짜와 함께 한 줄 등록하고, 상세 내용은 해당 파일에 둔다.
