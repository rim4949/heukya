# PATCH 27. 공동육아

출산 이후 공동육아 장면은 원본 그대로 유지.

후반 관계의 기본값:

- 오유리: 모델 + 배우자 + 부모
- 권도건: 태광건설 사장 + 배우자 + 부모
- 서무진: 흑야 핵심 실무자 + 배우자 + 부모
- 권유건 / 서유진 공동육아
- 외부 위협 시 권도건은 즉시 물리 대응, 서무진은 정보/시스템 대응
- 평상시에는 육아·먹이기·재우기·사진·누가 더 닮았나 같은 사소한 경쟁 지속

# PATCH 28. 나이 표기 일괄 수정

최신 기준:

- 오유리 26세
- 서무진 35세
- 권도건 36세

원문의:
- 오유리 28
- 서무진 38
- 권도건 39

직접적인 나이 언급은 전부 최신 기준으로 교체한다.

`스물여덟` 같은 서술도 `스물여섯`으로 수정.

세 사람 사이 나이차:
- 오유리 ↔ 서무진: 9세
- 오유리 ↔ 권도건: 10세
- 서무진 ↔ 권도건: 1세

# 편집 적용 원칙 요약

이 패치의 목적은 원문을 새로 쓰는 것이 아니다.

**원문 AI 장문 지문을 보존한 채, 새 캐논과 부딪히는 USER 턴과 상황만 갈아끼우는 것.**

따라서 최종본을 만들 때:

1. 원본을 복사한다.
2. 위 PATCH에 명시된 턴만 교체한다.
3. 명시되지 않은 AI 장문은 삭제하지 않는다.
4. 장면 점프가 생기는 곳에만 새 USER/AI 턴을 삽입한다.
5. 사건 순서와 날짜만 새 타임라인에 맞춘다.
6. 오유리의 관계 고착 이후 말투는 `형 + 반말`로 통일한다.

이 방식을 이후 전체 로그 편집에도 동일하게 적용한다.
